# Liam Learning App

A self-contained local web app generated from the supplied Biology and World Geography chapter PDFs.

## Run

From this folder:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

The app includes chapter navigation, clickable vocabulary, textbook-derived lesson blocks, study guides, worksheets, real client-side PDF worksheet/answer-key exports, knowledge checks, semester review/final exports, separate progress for Biology and World Geography, and a parent curriculum inspector.

Biology Chapter 16 is intentionally absent because it was not available in the supplied materials.
